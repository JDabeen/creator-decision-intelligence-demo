# Demo Guide

## 실행

1. [demo.html](../demo.html)로 이동합니다.
2. GitHub에서 **Download raw file**을 눌러 로컬에 저장합니다.
3. 내려받은 HTML 파일을 브라우저로 열어 버튼을 눌러봅니다.

**중요:** GitHub 저장소에서 HTML 파일을 클릭하면 소스 코드가 보일 수 있습니다. GitHub가 임의의 HTML 파일을 웹앱으로 호스팅하는 것은 아닙니다. 로컬 파일로 열면 시연할 수 있습니다.

## 시연 흐름

신규 유입/신뢰 형성 → 추천 후보 선택 → 가상 심층 조사 → Draft A/B 선택 → 텍스트 저장.

가상 사례만 있으며 실제 API 키, 유튜브 데이터, 채널 성과, 유료 서비스 호출은 없습니다.

## 나중에 영상 추가

Windows 화면 녹화로 1~2분간 전체 워크플로를 기록한 다음 GitHub README의 ‘시연 영상’ 섹션에 파일 또는 YouTube 공개/일부 공개 링크를 연결할 수 있습니다. 영상이 업로드되기 전에는 존재한다고 표시하지 않습니다.
