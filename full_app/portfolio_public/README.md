# Public evaluation exports

After completing a topic comparison, run `8_PORTFOLIO_EXPORT.bat`. The generated `evaluation_summary.json` contains **aggregate counts and evidence-check states only**. It intentionally excludes all topic titles, URLs, transcript excerpts, private audience and Studio data, scripts, credentials and home paths.

This is a workflow audit, **not a measured improvement in YouTube views**. For a public demo, use fabricated example data or separately obtain permission for any real data you publish.
