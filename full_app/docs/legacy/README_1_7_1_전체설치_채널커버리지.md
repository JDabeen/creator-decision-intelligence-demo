# v1.7.1 전체 설치본 — 주제 전략·채널 데이터 범위

v1.7 전체 프로그램과 v1.7.1 주제 전략 개선 패치를 통합했습니다. 추가로 Hermes evidence snapshot에 채널 데이터 커버리지 및 이용 가능한 Studio 수동 입력 실측치를 포함하도록 개선했습니다.

## 현재 지원

- 기존 A 엔진: 내 채널 YouTube Data API 및 기존 데이터 파이프라인으로 TOP 3 추천.
- Hermes B 엔진: A의 추천 결과를 보지 않은 채 같은 공통 실측 자료와 실제 확인된 웹 조사 결과로 TOP 3 추천.
- 승자 심화 / 인접 확장 / 신규 실험 전략 구분. 필요하면 같은 전략의 후보 3개도 제안 가능.
- 추천 선택 → 심층 조사 → 선택적 대본 생성.
- A/B는 제작 방법 간 비교이며 YouTube의 실제 트래픽 A/B 실험이 아닙니다.

## 내 채널 데이터 범위 및 한계

공개 영상 API의 채널 업로드 목록에서 **5–60분 길이**로 필터링한 카탈로그를 사용합니다. 해당 카탈로그 중 최대 200개 동영상의 제목, 공개 성과 메타데이터 및 설명 앞부분을 Hermes에 제공합니다. 현재 채널 데이터가 200개 이하이면 이 카탈로그 전체를 전달합니다. 조회수가 높은 8개도 별도 제공하지만 조회수만으로 성과 원인을 단정하지 않습니다.

수집 가능한 과거 대본은 최대 60개, 영상당 앞 950글자만 Hermes에게 제공합니다. YouTube 영상에 자막이 없거나 수집에 실패했다면 대본 정보가 비어 있을 수 있습니다. 비공개 Studio 데이터(CTR, 노출, 시청 유지율 등)는 API 키로 자동 조회되지 않습니다. 수동 입력한 Studio CSV가 있으면 측정값과 최신 시청자 스냅샷을 함께 제공합니다. 코드 내 기본 시청자 프로필은 이전 제공된 자료로, 현재 값임을 보장하지 않습니다.

`topic_experiments/<실행 폴더>/evidence.json`은 실제로 모델에 전달된 공통 근거입니다. `comparison.json`의 `channel_coverage`는 전달된 채널 메타데이터 개수, 대본 발췌 개수, Studio 수동 입력 개수를 기록합니다. 이 숫자는 분석 내용이 모두 정확하다는 보증이 아니라 **입력 커버리지**만 뜻합니다.

## 이전 개인 데이터 삭제 시

이 전체 ZIP에는 `.env`와 개인 데이터 캐시를 넣지 않았습니다. `.env.example`을 `.env`로 복사해 사용자 API 키를 입력해야 합니다. 기본 데이터 폴더는 `Desktop/youtube_consultant_data`이며, 폴더가 남아 있으면 재사용합니다. 해당 데이터 폴더까지 삭제됐다면 기존 수동 입력값과 캐시는 복구되지 않습니다.
