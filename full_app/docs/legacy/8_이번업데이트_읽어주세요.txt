YouTube Content Consultant v1.1 — 결과 간소화 + 독립 재설계 (2026-10-18)

[기존 버전과 무엇이 달라졌나?]
- Draft A 전체 글을 처음부터 펼쳐 보여주지 않습니다. 요약을 보고 필요하면 원문을 펼칩니다.
- Draft B가 끝나면 페이지 맨 위에 '실행 결과, 웹 검색 확인 여부, 변경 핵심 3~4개'를 보여줍니다.
- 원하는 구간을 선택해 Draft A와 B를 좌우 비교할 수 있습니다.
- Draft A/B 전체, Critic Report는 접어 두었습니다.
- 'Draft B 대본 다운로드' 버튼이 있습니다.
- 중복 '1. 1. 질문...' 파트 번호 표시를 바로잡았습니다.

[두 가지 생성 방식]
① 독립 재설계 · 새 대본 (신규 기본값): Hermes에게 실제 Research를 읽고, 새로운 콘셉트·오프닝·순서·훈련 시나리오를 설계하도록 요청합니다. 가능하면 검증할 질문 2~4개를 고르고 웹 검색을 시도하도록 지시합니다. 그 비평/기획 보고서를 별도의 대본 작성 모델에 전달해 새로운 Draft B를 작성합니다.
② 기존 초안 정교화: 이전 버전처럼 Draft A를 보존하면서 제한적으로 개선합니다.

[중요한 제한]
- Hermes는 검색을 '요청'받지만 실제 검색 도구 호출은 검색 백엔드 및 Docker 환경에 따라 다릅니다.
- 웹 검색 호출 흔적이 없으면 '미확인'이라고 표시합니다. 외부 조사 성공을 보장하거나 꾸며내지 않습니다.
- 필요하면 .env에 TAVILY_API_KEY 또는 EXA_API_KEY를 추가해 Hermes 웹 도구의 검색 백엔드를 설정할 수 있습니다(별도 서비스 조건/비용 확인).
- SUPADATA_API_KEY는 유튜브 시장 영상 자막 확보용이며 Hermes 자체의 일반 웹 검색 키가 아닙니다.
- Hermes는 계속 웹 검색·추출만 허용하는 안전 정책입니다. Windows 파일/터미널/시스템 권한을 풀지 않았습니다.
- 모델·검색 서비스 API 사용량에 따라 비용이 발생할 수 있습니다.
- 검증된 외부 시장 자막이 부족하면 기존 Coverage Gate는 유지됩니다.

[설치]
1. 이 ZIP을 새 폴더에 압축 풉니다. 이전 정상 작동 폴더는 삭제하지 마세요.
2. 이전 폴더의 .env 파일을 새 폴더(0_START_WITH_HERMES.bat이 있는 폴더)에 복사합니다.
3. Docker Desktop이 실행 중이면 0_START_WITH_HERMES.bat을 더블클릭합니다.
4. Draft A 생성 후 Draft B 화면에서 '독립 재설계 · 새 대본' + Hermes Agent를 선택합니다.
5. '새 Draft B 만들기'를 누르고, 결과 페이지의 핵심 변화/선택 비교를 봅니다.

[검증]
Python 문법 검사 및 로컬 모의 API 포함 단위 테스트 13개 통과.
실제 사용자 PC의 Docker·Hermes·검색 제공자·OpenAI 연동을 새 버전으로 종단 간 시험하지는 못했습니다.
기존 Hermes 연결 정상 여부는 7_CHECK_HERMES.bat으로 별도 확인할 수 있습니다.
데이터/캐시 위치, .env 키 형식, Docker Compose 이미지 및 개인 파일 비노출 정책은 변경하지 않았습니다.
