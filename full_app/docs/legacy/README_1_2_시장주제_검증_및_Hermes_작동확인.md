# YouTube Content Consultant v1.2 — 시장 우선 + Hermes 실행 감사

## 이번 버전의 목적

**좋아 보이는 대본 첨삭을 넘어**, 시장에 경쟁력이 있는 주제를 먼저 고르고, 실제 경쟁 영상 근거와 시청자의 인지적 부담을 고려하여 **필요하면 완전히 다른 대본 구조**를 제안합니다.

### 1. 사용 흐름 (별도 설치·덮어쓰기 없음)

1. ZIP을 **새 폴더**에 압축 해제합니다. 이전 정상 작동 버전은 그대로 둡니다.
2. 기존 프로그램의 `.env` 파일을 새 폴더( `0_START_WITH_HERMES.bat` 옆)로 복사합니다. 새 API 키는 필요 없습니다. `SUPADATA_API_KEY`는 이전처럼 유지합니다.
3. Docker Desktop을 켠 뒤 `0_START_WITH_HERMES.bat` 더블클릭.
4. 시장조사에서 주제 후보가 나오면, 원하는 후보 아래 **「Hermes로 주제 경쟁력 먼저 검증」**을 눌러 주제 적합성을 먼저 봅니다. 생략하고 초안부터 만들 수도 있습니다.
5. Hermes 판정이 `새 주제 재조사 권고`라면 **「제안 주제 다시 시장조사」**를 눌러야 합니다. 검증하지 않은 새 주제의 성공을 약속하지 않습니다.
6. Draft A 이후 **Hermes Agent (Docker)**, **독립 재설계 · 새 대본** 선택.
7. 필요하면 「Hermes가 실제로 작동하는지 확인하기」에서 ① API/권한 점검, ② 실전 웹 검색 테스트를 실행합니다. **②는 모델 API 비용이 들 수 있습니다.**
8. **「새 Draft B 만들기」** 실행 → 주제 판정/경쟁 영상/변화 요약을 먼저 보고, 긴 본문은 아래에서 펼쳐봅니다.

### 2. 새로 확인할 수 있는 것

- Hermes **API 인증과 도구 권한** 확인 (웹 관련 도구 외에는 실행되지 않도록 검사)
- **실제 함수 호출과 도구 응답 횟수** 구분, 검색 요청 요약과 도구 응답 URL 표시 (없으면 '미확인')
- 경쟁 영상 **제목, 채널, 조회수, 채널배수, 업로드 날짜, 자막 확보 여부, 영상 링크**
- 주제 결정: `KEEP` / `REFRAME` / `RESEARCH_NEW` (구조화된 결과를 파싱할 때만 표시)
- Hermes 비평 기준: **주제 자체의 클릭 이유와 경쟁 신호, 채널 적합성, 근거의 한계, 인지적 부담, 설명·예시의 간결함**
- 새 주제로 전환하는 경우 **시장 재조사**를 시작할 수 있는 버튼
- Critic Tool Trace와 시장 관측값을 Run JSON에 저장 (개인 실행 데이터 폴더에 저장)

### 3. 무엇을 보장하지 않는가

- Hermes 모델 응답과 실제 웹 검색은 다릅니다. **검색 기능이 반드시 실행되거나 올바른 결과를 내는 것은 아닙니다.**
- 실제 웹 검색은 검색 서비스 설정(`TAVILY_API_KEY` 또는 `EXA_API_KEY` 등)에 의존합니다. Supadata 자막 API 키는 일반 웹 검색 API 키가 아닙니다.
- 검색 도구가 URL을 반환했다는 사실은 **해당 자료의 신뢰성을 검증했다는 뜻이 아닙니다.**
- 후보 영상은 검색으로 선택된 **편향된 표본**입니다. 업로드 기간과 채널 규모의 영향을 고려해야 하며 미래 조회수를 예측하거나 시장 전체 수요를 확정할 수 없습니다.
- `RESEARCH_NEW`는 **새 시장조사가 필요하다는 제안**이지 신규 주제 검증 완료가 아닙니다.
- 영상 대본의 교육 효과가 실제로 더 좋다는 실험적 증거는 없습니다. 본인이 결과를 비교해 최종 판단해야 합니다.
- 시장 Transcript Coverage Gate는 기존처럼 유지합니다. 자료가 부족하면 Draft A 생성 자체를 막습니다.

### 4. 보안 및 비용

- Docker 컨테이너는 이전과 동일하며 Windows 프로젝트 폴더, 호스트 파일, 터미널 도구를 제공하지 않습니다.
- YouTube/시장 데이터와 제한된 Draft A 텍스트만 에이전트에 전달합니다. `.env` 키는 모델 프롬프트에 포함되지 않습니다.
- `.env`, 캐시, 로컬 개인 실행 결과 등은 새 ZIP에 포함되지 않았습니다.
- Hermes 자체를 설치·실행하는 데 이용료는 없지만 **OpenAI 모델/API, 외부 검색 제공자, Supadata** 사용량에 따라 비용이 발생할 수 있습니다.

### 5. 검증 상태

코드 문법 검사 + 오프라인 mock 서버 테스트 + 근거/도구 실행 파싱 단위 테스트는 수행했습니다.
이 ZIP을 사용자의 Windows / 실제 Docker Hermes / 실제 YouTube / Supadata 데이터로 **종단간 검증하지는 못했습니다.**

**개발 종료 목표:** ① 시장 자막 확보 → ② 주제 평가 → ③ Draft A → ④ Hermes Critic의 실제 응답 확인 → ⑤ 새로운 Draft B → ⑥ A/B 선택 및 결과 저장. 추가 기능은 이후 버전으로 미룹니다.
