Hermes API 도구 목록 응답 형식 수정본 (2026-10-11)

[실행은 하나만]
1. 이 ZIP을 새 폴더에 압축을 풉니다. 기존 프로그램은 삭제하지 마세요.
2. 이전 폴더의 .env 파일을 새 폴더에 복사합니다. API 키는 채팅에 올리지 마세요.
3. Docker Desktop이 Engine running이면 0_START_WITH_HERMES.bat을 실행합니다.

[성공 확인]
