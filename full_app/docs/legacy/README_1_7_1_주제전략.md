# v1.7.1 · 기존 히트 심화 / 인접 확장 / 신규 실험

## 왜 바꿨나
기존 TOP3 추천은 채널의 커버리지 공백과 서로 다른 시장 문제를 우선하도록 설정돼 있었습니다. 그래서 잘된 주제의 의미 있는 후속편이 밀릴 가능성이 있었습니다.

## 달라진 판단
A(기존 AI)와 Hermes 모두 **승자 심화, 인접 확장, 신규 실험** 중 각 추천 주제의 전략 경로를 결정합니다.
- 각 경로에서 하나씩 추천하도록 강제하지 않습니다. 한 경로에서 세 후보를 모두 제시할 수 있습니다.
- 승자 심화는 같은 원고를 반복하는 재탕이 아니라 다른 시청자 문제/훈련/결과를 제공해야 합니다.
- 조회수와 업로드 시점, 가능하면 Studio CTR/노출/시청지속률을 고려하되 데이터가 없으면 성공 원인을 단정하지 않습니다.
- Hermes에는 내 채널 실제 성과와 공개 과거 대본 발췌, 경쟁 영상의 공통 원자료만 공유합니다. A 추천 결과는 공개하지 않습니다.
- Hermes의 채널 동영상 근거 ID는 실제 공유된 내 채널 ID와 대조합니다. 존재하지 않는 ID는 기록에서 제외되고 경고됩니다.

## 사용법
v1.7의 프로그램 폴더(0_START_WITH_HERMES.bat 있는 곳)에 패치 ZIP을 풀어 폴더 구조 그대로 덮어씁니다.
`.env`, 기존 컨테이너, 캐시, 채널 데이터는 변경하지 않습니다.
다시 실행한 뒤 **시장 조사 새로 시작하기**를 눌러야 새로운 추천 기준이 적용됩니다. 기존에 저장된 A/B 결과에는 전략 분류가 없을 수 있습니다.
'주제 비교·선택'에서 각 카드의 한 줄 전략 경로를 확인하세요. 선택 후 '근거·위험 보기'에서 해당 전략의 판단 근거를 확인할 수 있습니다.

## 포트폴리오용 정직한 한계
- 3개 후보는 실제 실험군 간 A/B 성과 실험이 아닙니다.
- 분류와 기획 이유는 AI가 제시하는 전략적 가설이지 조회수 상승을 보증하지 않습니다.
- 전체 채널의 승리 패턴을 자동으로 식별하는 과학적 통계 검정이 아닙니다. 표본이 작고 조회수, 업로드 시점 및 제목·썸네일 효과가 혼재합니다.
- 실측 URL 확인과 시청자 수요 검증은 별개이며, 추천 채택 이후 7일/28일의 실제 결과를 측정해야 합니다.
- Windows에서 실제 Hermes 웹 검색 및 Streamlit UI 동작은 아직 현장 검증 전입니다.
