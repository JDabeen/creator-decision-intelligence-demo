# v1.6.1 Hermes 브라우저 도구 검사 수정

## 무엇이 고쳐졌나?

v1.6에서 Docker 브라우저를 허용하면 Hermes 공식 `browser` 도구 묶음에서 `browser_vault_*` 5개가 함께 나타났습니다. 그런데 기존 연결 검사기가 해당 이름들을 모른다고 판단해 앱을 시작하지 못했습니다. 이 다섯 **공식 이름만** 허용 목록에 추가하고, 미등록 도구나 Windows 터미널·파일 관련 도구 차단은 유지했습니다.

- Docker Compose 이미지, 볼륨, 포트, 권한, API 키 처리 **변경 없음**
- A/B 다음 주제 추천, 캐시, 유튜브 조사, Draft A/B 코드 **변경 없음**
- `YRA_HERMES_BROWSER=1` (기본값) 및 웹 검색 병행 가능
- 안전 검사기는 API 도구의 **이름만 검사**합니다. `browser_vault_*`의 실제 실행을 막지는 않습니다. 네 계정과 브라우저 프로필은 제공하지 마세요.

## 사용법

1. 새 폴더에 압축을 풀고 기존 `.env` 파일을 복사합니다.
2. `.env`에 `YRA_HERMES_BROWSER=0`이 있다면 `1`로 변경하거나 해당 줄을 삭제합니다.
3. Docker Desktop이 켜진 상태에서 `0_START_WITH_HERMES.bat`을 실행합니다.
4. `[Hermes] 인증된 API 연결 성공`이 나오면 앱의 `웹 검색 실제 실행 테스트`를 실행합니다.
5. 호출 횟수, 응답, 출처 URL까지 확인돼야 실제 조사가 된 것입니다.

오프라인 모의 게이트웨이 테스트는 연결 정책만 검증합니다. 실제 Windows Docker의 브라우저와 외부 검색 성공은 사용자 환경에서 확인해야 합니다.
