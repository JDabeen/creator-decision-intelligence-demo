YouTube Content Consultant v2.2 — 안정화 전체 설치본
===========================================
1. 이 ZIP을 새 폴더에 풀고 .env.example을 .env로 복사합니다.
2. .env에서 YOUTUBE_API_KEY와 OPENAI_API_KEY를 설정합니다.
3. Docker Desktop을 켜서 Engine running을 확인합니다.
4. 0_START_WITH_HERMES.bat 더블클릭합니다.
5. 앱에서 다음 주제 찾기 → A/Hermes 비교·선택 → 이 주제로 더 찾기.
   대본은 마지막 선택 기능이며, 주제를 확정하지 않아도 됩니다.

주제 평가에는 '시장 영상 연결 / 조사 링크 확보 / 직접 근거 부족'이 표시됩니다.
이 표시는 실제 조회수 성공 예측이나 시장 수요 입증이 아닙니다.
Hermes 웹 조사에 실패하면 A 후보는 보존하고 오류를 보여줍니다.

검증: 7_OFFLINE_TEST.bat (요금 없는 모의 테스트).
완주 후 공개용 평가 요약: 8_PORTFOLIO_EXPORT.bat.

기존 개인 데이터는 기본적으로 바탕화면\youtube_consultant_data에 저장됩니다.
이 ZIP에는 기존 API 키와 사용자 입력 캐시가 없습니다.
Windows Chrome 로그인·문서/사진 폴더는 Docker Hermes에 연결하지 않았습니다.
하지만 AI API와 웹 검색으로 전송하는 텍스트는 외부 서비스에 노출될 수 있습니다.

'코드 테스트 완료'는 Windows 실제 Hermes 시장조사 성공을 의미하지 않습니다.


v2.2 추가 확인 (2026-10-31)
--------------------------------------
- B1 심층 조사에서 발생한 HTTP 429 문제: 기존 조사 영상 ID 우선 재사용 및 검색 캐시, 검색 한도 소진 시 제한적/미검증 상태로 복구.
- 오류 화면에 API 키가 드러나지 않도록 오류 원문/traceback 표시 차단. 이미 노출된 API 키는 재발급 및 제한 필요.
- 주제 선택만으로 제작 확정하지 않음. '이 주제로 더 찾기'는 탐색이고, 조사 완료 뒤 '제작 확정'을 별도 클릭해야 기록.
- 선택 후보의 관측 근거(내 영상 조회수·댓글 절대 수, 경쟁 영상, SerpApi 상대 관심도) 그래프.
- SerpApi가 설정됐다면 추천 생성 전 탐색 검색어 관심도 수집을 시도. 최종 주제 검색량 예측은 아직 불가능.
- 데이터 저장: 바탕화면\YT_Channel_Strategy, 바탕화면\youtube_consultant_data (기존 폴더를 삭제하지 마세요).
- 개인 기록 백업: 10_BACKUP_STRATEGY_DATA.bat. 백업 ZIP은 외부 공개 금지.
- 세부 변경사항 및 한계: RELEASE_NOTES_V2_2.md
- 실제 Windows + Docker Hermes 통합 구동은 사용자의 PC에서 확인해야 합니다.
