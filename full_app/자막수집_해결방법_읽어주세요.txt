시장 자막 IP 차단 시 자동 복구 (2026-10-11)

기존 프로그램, Hermes, 개인 캐시, Transcript Coverage Gate는 변경하지 않았습니다.
YouTube 비공식 자막 요청이 차단되면 시장 영상에 한하여 Supadata의 기존 자막(native)을 읽습니다.
기본으로 AI 오디오 전사는 켜지지 않습니다. 외부 API는 별도 무료 계정/키가 필요합니다.

사용 방법
1. 기존과 같이 0_START_WITH_HERMES.bat 실행
2. Research Coverage 부족이면 '자막 수집 복구' 펼치기
3. https://dash.supadata.ai 에서 무료 API 키 발급
4. 앱에 키를 붙여넣고 '키 등록 후 시장 자막 다시 조사' 클릭
5. 외부자막까지 부족하다면 YouTube 영상의 '스크립트 표시' 복사/붙여넣기 보완

기술 및 비용 경계
- 기본 경로: 기존 캐시 > YouTube 직접 자막 > Supadata native (옵트인)
- Supadata 키 미등록 시 기존과 똑같이 작동하며 품질 검사를 우회하지 않습니다.
- free tier는 서비스에서 변경할 수 있으므로 대시보드에서 잔여 크레딧을 확인하세요.
- native 자막 조회 1건당 1크레딧(2026-10-11 공식 문서 기준). 다른 요금제 이용 시 계약을 확인하세요.
- `mode=auto` 또는 `mode=generate` 사용 금지: 추가 AI 음성인식 크레딧 자동 사용을 피합니다.
- API 성공(HTTP 200)이더라도 글자가 너무 적으면 '실패' 처리하며 연구 품질을 유지합니다.
- 외부 provider 오류를 유튜브 IP 차단으로 오인하지 않고 각각 오류 표시합니다.
- API 키는 DATA_ROOT/cache 상위 디렉터리의 supadata_key.txt에 저장합니다. ZIP에 포함되지 않습니다.
- 다른 사람의 영상 대본은 연구·비교 목적으로 사용하고 표현/순서/원문을 복제하지 않습니다.
- 여기서는 외부 서비스의 실계정 호출을 검증하지 못했습니다. 모의 응답 테스트만 완료했습니다.
